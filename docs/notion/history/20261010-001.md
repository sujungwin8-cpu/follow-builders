# API 키 미설정으로 중단된 피드 생성기 수정

## 작업 목적
예약 실행이 콘텐츠 수집 전 API 키 검사에서 종료되는 문제를 수정하고 키 없이 가능한 공개 블로그 수집을 분리합니다.

## 변경 내용
기본 모드는 블로그를 먼저 수집하고 키 없는 공급원을 건너뜁니다. 명시적인 X·팟캐스트 단독 모드는 키를 요구합니다. 공급원별 오류를 격리하고 기존 피드·중복 제거 상태를 보존하며 `feed-status.json`과 Actions 요약을 남깁니다. 실패를 단순한 새 글 0건으로 처리하지 않습니다.

실제 사이트 확인 중 Claude Blog가 `/resources/articles`로 이동한 사실을 확인해 새 주소·본문 추출·본문 게시일 필터를 반영했습니다. 실패한 팟캐스트 전사문을 이미 처리한 항목으로 기록하지 않도록 했습니다. HTTP 요청에 제한 시간을 적용했습니다.

## 변경 위치
`scripts/generate-feed.js`, `scripts/test/`, `scripts/package.json`, `config/default-sources.json`, `.github/workflows/generate-feed.yml`, `README.md`, 현재 설명·사용설명서·이 이력입니다.

## 확인 결과
로컬 Node.js 24에서 20개 회귀 시험과 JavaScript 구문 검사를 통과했습니다. 시험은 키 조합, 명시 모드 오류, 인증·접속 실패 시 다른 피드 수집 및 기존 데이터 보존, 중복 제거, Claude 구·신 경로·본문·날짜 처리를 포함합니다. 유료 API는 모의 응답으로 시험했으며 실제 키 검증을 수행하지 않았습니다. 코드 변경 후 실제 GitHub 실행·커밋·노션 게시 성공은 이 기록 작성 시점에 확인 기록 없음입니다.

## 적용 상태
로컬 수리·검증 완료 단계입니다. 기본 브랜치 적용 및 실제 서비스 실행 결과는 후속 기록으로 구분합니다. 매장 설치·외부 알림 전송은 수행하지 않았습니다.

## 남은 작업
GitHub 반영 후 실제 블로그 수집과 커밋을 확인해야 합니다. X·팟캐스트는 키·권한·서비스 사용량 설정과 별도 실제 시험이 필요합니다. 키 발급이나 비용 발생 계약은 수행하지 않았습니다.
