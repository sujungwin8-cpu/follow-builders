# follow-builders

## 현재 상태
AI 개발자 소식과 팟캐스트·블로그를 모아 요약하는 원본 프로젝트의 포크입니다.

공개 포크입니다. 아래 기능은 원본 README 설명이며 이 계정에서 예약 수집·알림을 실제 사용 중이라는 뜻은 아닙니다.

문서 등록 기준: 2026-09-24. 기본 브랜치 `main`의 [확인한 버전](https://github.com/sujungwin8-cpu/follow-builders/commit/c2cfc11ca39cb5f7778d8cafeb9111085d4a197a)을 기준으로 정리했습니다.

## 주요 기능
X 게시물, 팟캐스트, 회사 블로그를 모아 일간·주간 요약과 원문 링크를 제공하는 흐름을 설명합니다.

## 실행 방법
원본 안내는 지원하는 에이전트에 스킬을 설치한 뒤 설정하는 방식입니다. 이번에는 설치·예약·메시지 전송을 실행하지 않았습니다.

## 설정과 연결
외부 콘텐츠 공급과 알림 채널 설정이 관련됩니다. 이 계정의 키·알림 대상·예약 활성화 여부는 확인하지 않았습니다.

## 변경 위치
`prompts/`: 요약 지침. `scripts/`: 처리 도구. 기존 피드 자동화는 문서 자동화와 별개입니다.

이번 변경은 `docs/notion/`, 노션 게시 워크플로와 작업 안내뿐입니다.

## 남은 작업
원본과 사용자 수정분, 실제 사용 설정과 수집 성공 결과를 구분해서 기록해야 합니다.
